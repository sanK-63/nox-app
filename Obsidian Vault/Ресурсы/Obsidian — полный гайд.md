# Obsidian — полный гайд

Obsidian — программа для заметок на markdown с графом связей, плагинами и локальным хранением.

---

## 1. Философия

Obsidian держится на трёх принципах:

1. **Локальность** — все заметки это обычные `.md` файлы. Никакой базы данных, никакой привязки к облаку. Файлы твои навсегда.
2. **Связи** — заметки связываются через `[[двусторонние ссылки]]`. Из любой заметки можно перейти к связанной и обратно.
3. **Расширяемость** — сообщество пишет плагины под любую задачу. 1500+ плагинов в Community Store.

## 2. База: markdown + ссылки

### Форматирование

```md
# Заголовок 1
## Заголовок 2
### Заголовок 3

**жирный текст**
*курсив*
==выделение цветом==
~~зачёркнуто~~

- маркированный список
1. нумерованный список

> цитата

`код inline`

\`\`\`python
# code block
print("hello")
\`\`\`
```

### Внутренние ссылки

```md
[[Название заметки]]              — ссылка на заметку
[[Название|Текст ссылки]]          — ссылка с другим текстом
[[Заметка#Заголовок]]             — ссылка на конкретный заголовок
[[Заметка#^block-id]]             — ссылка на блок
![[Изображение.png]]              — вставить изображение
![[Заметка]]                      — трансклюзия (встроить содержимое)
```

### Теги

```md
#важный-тег

Вложенные: #llm/transformer #tech/programming
```

## 3. Внутренние возможности (core)

### Граф (Graph View)

Визуализация связей между заметками. Каждая заметка — узел, каждая ссылка — ребро.

```
Настройки графа:
  ├── Цветовые группы — задать цвет для папки или тега
  ├── Фильтры — показать только определённые теги
  ├── Глубина — сколько шагов от текущей заметки показывать
  └── Анимация — включить для "живого" графа
```

### Canvas

Бесконечное полотно для mindmap, схем, мудбордов. Можно таскать заметки, изображения, рисовать стрелки.

### Daily Notes

Шаблон для ежедневных записей. Создаётся по кнопке или автоматически.

```
Шаблон daily note (/_templates/Daily.md):
---
date: {{date}}
tags: [daily]
---

## Задачи
- [ ]

## Заметки

```

### Backlinks (обратные связи)

Панель внизу заметки — показывает, какие другие заметки ссылаются на текущую. Бесплатно и автоматически.

### Properties (YAML frontmatter)

Метаданные в начале файла. Используются для тегов, дат, статусов, кастомных полей.

```yaml
---
title: Моя заметка
tags: [важно, tech]
date: 2026-06-15
status: черновик
---
```

### Панели (Panels)

Можно открыть сколько угодно панелей рядом:
- Сплит по горизонтали / вертикали
- Новое окно (Ctrl+Shift+N)
- Закрепить панель (Pin)

### Поиск

```
Ctrl+Shift+F — глобальный поиск
  Поддержка regex: /pattern/
  Путь: path:Исследования
  Тег: tag:#llm
  Блок: block:definition
```

## 5. Организация заметок (методы)

### PARA (Tiago Forte)

```
Projects   — активные проекты (с дедлайном)
Areas      — зоны ответственности (без дедлайна)
Resources  — темы и исследования
Archive    — завершённое
```

### Zettelkasten

```
Каждая заметка — одна идея.
Связи между заметками важнее папок.
Идентификатор — дата (202606151200).
```

### MOC (Map of Content)

Заметка-навигатор, которая собирает ссылки на группу заметок по теме. Примеры в этом хранилище: [[Исследования/index]], [[Исследования/LLM/index]].

## 6. Продвинутые техники

### Dataview — примеры

```dataview
TABLE file.cday as Created, tags as Tags
FROM #llm
SORT file.cday DESC
```

```dataview
TASK
FROM #daily
WHERE !completed
GROUP BY date
```

### Templater — динамические шаблоны

Вставка даты, времени, заголовка из названия файла:

```js
<% tp.date.now("YYYY-MM-DD") %>
<% tp.file.title %>
<% tp.system.clipboard() %>
```

### Hotkeys (шорткаты)

| Действие | Шорткат |
|----------|---------|
| Палитра команд | `Ctrl+P` |
| Быстрый переход | `Ctrl+O` |
| Поиск | `Ctrl+Shift+F` |
| Новая заметка | `Ctrl+N` |
| Открыть Daily Note | `Ctrl+Shift+D` |
| Backlinks | `Ctrl+Shift+B` |
| Вставить шаблон | `Ctrl+Shift+T` |
| Закрепить панель | `Ctrl+Shift+P` |
| Просмотр графа | `Ctrl+Shift+G` |

### Sync (официальный, платный)

- Шифрование E2E
- История версий
- Работает на iOS, Android, Desktop
- $5/мес

### Git (бесплатная альтернатива Sync)

Через плагин **Obsidian Git**:
```bash
# Автокоммит каждые N минут
# Пуш в GitHub/GitLab
# Клонировать на другой ПК
```

## 7. Сравнение

| | Obsidian | Notion | OneNote | Logseq |
|--|----------|--------|---------|--------|
| Локально | ✅ .md | ❌ облако | ⚠️ есть кэш | ✅ .md |
| Связи | `[[ссылки]]` | `@mention` | нет | `[[ссылки]]` |
| Плагины | 1500+ | мало | нет | среднее |
| Граф | ✅ | ❌ | ❌ | ✅ |
| Оффлайн | ✅ | ❌ | ✅ | ✅ |
| Цена | бесплатно / $5 sync | $10/мес | бесплатно | бесплатно |
| База данных | Dataview | Notion DB | нет | queries |
