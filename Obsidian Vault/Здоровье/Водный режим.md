# Водный режим

## Почему это важно

| % потери воды | Симптом |
|:-------------:|---------|
| 0-1% | Норма |
| 1-2% | Жажда, ↓ фокус на 15% |
| 2-3% | Головная боль, ↓ физическая производительность |
| 3-5% | Сильная усталость, головокружение |
| >5% | Тепловой удар, опасность |

**Правило:** если хочется пить — ты уже обезвожен на 1-2%.

## Норма воды

| Фактор | Формула |
|--------|---------|
| Базовая | 30-35 мл на 1 кг веса |
| Пример (70 кг) | 2.1-2.5 л/день |
| С тренировкой | +0.5-1 л на час активности |
| В жару | +0.5-1 л |
| На кофе/чай | +0.3 л на каждую чашку (диуретик) |

## Как пить больше

- Бутылка 1.5л на столе — цель выпить за день
- Приложения: WaterMinder, Plant Nanny
- Лимон/огурец/мята — вкуснее
- Стакан воды перед едой — +ещё и аппетит снижает

## Признаки обезвоживания

| Степень | Симптомы |
|---------|----------|
| Лёгкая | Сухость во рту, жажда, редкий туалет |
| Средняя | Головная боль, усталость, тёмная моча |
| Сильная | Головокружение, спутанность сознания |

Цвет мочи: светло-жёлтый ✅ / тёмный ⚠️ / прозрачный ⚠️ (перегидратация).

## Электролиты — когда нужно

| Ситуация | Нужны | Что добавить |
|----------|:-----:|--------------|
| Тренировка >60 мин | Да | Натрий + калий + магний |
| Жара / потливость | Да | Натрий (соль, 1-3 г) |
| Кето / LCHF | Да | Натрий + калий (больше) |
| Обычный день | Нет | Достаточно из еды |

**Простой электролитный напиток:**
```
500 мл воды + 1/4 ч.л. соли + 1/2 лимона + 1 ст.л. мёда
```

## Типы воды

| Тип | Для чего |
|-----|----------|
| Обычная (фильтр) | База |
| Минеральная (столовая) | Микроэлементы |
| Щелочная | ↑ pH — для кислотного рефлюкса |
| С лимоном | +С, вкус |
| Кокосовая | Электролиты (после тренировки) |
| Газированная | Если надоела обычная |
