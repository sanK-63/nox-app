# Анализ питания

Оценка текущего рациона, поиск дефицитов, рекомендации по улучшению.

## Как оценить свой рацион

### Ежедневный трекинг

Записывать всё, что съедено за день, и сравнивать с нормой:

```
         Твоё     Норма     Разница
Ккал     2100     2300      -200   ✅
Белки     75      120       -45    ⚠️
Жиры      70       70        0     ✅
Углеводы 290      310        -20   ✅
Вода     1.2 л    1.8-2 л   -0.6   ⚠️
```

Норма из [[Здоровье/КБЖУ расчеты]].

### Типичные проблемы

| Проблема | Как выглядит | Что делать |
|----------|-------------|------------|
| **Мало белка** | <1.2 г/кг веса | Добавить курицу, творог, протеин |
| **Мало жиров** | <0.6 г/кг веса | Добавить орехи, масло, авокадо |
| **Много сахара** | >10% калорий из сахара | Убрать сладкие напитки, заменить снеки |
| **Мало клетчатки** | <20 г/день | Добавить овощи, цельнозерновые |
| **Мало воды** | <1.5 л/день | Поставить бутылку на стол |
| **Нерегулярно** | Пропуски еды, переедание вечером | 3-4 приёма в день, стабильное время |

## Дефициты — что чаще всего не хватает

| Нутриент | Зачем | Симптомы дефицита | Где брать |
|----------|-------|-------------------|-----------|
| **Витамин D** | Иммунитет, кости, настроение | Усталость, слабость, частые болезни | Солнце, рыбий жир, добавки |
| **Омега-3** | Мозг, сердце, воспаление | Сухая кожа, плохая память | Рыба (лосось/скумбрия), льняное масло |
| **Железо** | Кровь, энергия | Усталость, бледность | Говядина, печень, гречка, яблоки |
| **Магний** | Сон, мышцы, нервы | Судороги, тревога, плохой сон | Орехи, шпинат, гречка, какао |
| **Йод** | Щитовидка | Вялость, набор веса | Морская капуста, йодированная соль |
| **Цинк** | Иммунитет, кожа, волосы | Прыщи, выпадение волос | Тыквенные семечки, говядина, устрицы |
| **B12** | Нервы, кровь | Усталость, онемение пальцев | Мясо, яйца, печень (веганам — добавки) |
| **Кальций** | Кости, зубы | Хрупкие кости | Молочка, сыр, кунжут, зелень |

## Рекомендации по улучшению

### Общие принципы

1. **Белок в каждом приёме** — завтрак, обед, ужин. 20-40 г за раз
2. **Овощи в каждый приём** — минимум половина тарелки
3. **Сложные углеводы** — каши, цельнозерновые вместо белого хлеба/сахара
4. **Жиры — качественные** — орехи, масла, рыба
5. **Сахар — минимум** — не больше 25 г/день
6. **Вода — 30 мл/кг веса** — ~2 л для 70 кг
7. **Режим** — есть в одно и то же время, не пропускать завтрак

### Как добавить белок без увеличения калорий

| Вместо | Добавить | + белка | + ккал |
|--------|----------|:-------:|:------:|
| Кофе утром | Кофе + протеин | +24 г | +110 |
| Бутерброд | Творог/сыр + хлеб | +15 г | +150 |
| Макароны | Макароны + фарш/курица | +25 г | +200 |
| Салат без мяса | Салат + тунец/курица | +20 г | +100 |
| Йогурт питьевой | Греческий йогурт | +12 г | +100 |
| Каша на воде | Каша на молоке | +8 г | +80 |
| Омлет из 2 яиц | Омлет из 4 яиц | +14 г | +150 |

### Чек-лист здорового дня

- [ ] Завтрак с белком (яйца/творог/протеин)
- [ ] 3-4 порции овощей (300-400 г)
- [ ] Фрукты (1-2 шт)
- [ ] Вода 1.5-2 л
- [ ] Белок ≥ 1.6 г/кг
- [ ] Нет сладких напитков
- [ ] Последний приём за 3 ч до сна

## Чек-лист недели

- [ ] Рыба ≥ 2 раза (Омега-3)
- [ ] Красное мясо ≥ 1 раз (железо, B12)
- [ ] Печень/субпродукты ≥ 1 раз (железо, цинк)
- [ ] Орехи/семечки ежедневно (30 г)
- [ ] Молочка или заменители ежедневно (кальций)
