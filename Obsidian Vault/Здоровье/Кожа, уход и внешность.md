# Кожа, уход и внешность

Состояние кожи, бьюти-рутины, волосы, ногти.

---

## Что влияет на кожу изнутри

| Фактор | Эффект |
|--------|--------|
| Сахар / высокий ГИ | Гликация → AGEs → морщины |
| Омега-3 | ↓ воспаление, ↓ акне |
| Цинк | ↓ акне, заживление |
| Коллаген + C | Эластичность, увлажнение |
| Вода | Увлажнение, тургор |
| Сон <6ч | ↑ кортизол → ↓ коллаген, ↓ барьер |
| Алкоголь | Обезвоживание, расширение пор |
| Курение | Преждевременное старение ×2 |

---

## Бьюти-рутина

### Утро (3 шага)
- [ ] Умывание (мягкое, без SLS)
- [ ] Увлажнение (гиалуроновая кислота / алоэ)
- [ ] SPF 30-50 (если выходишь на улицу — обязательно)

### Вечер (4-5 шагов)
- [ ] Гидрофильное масло / мицеллярка — снять макияж/SPF
- [ ] Второе умывание (пенка / гель)
- [ ] Тоник / эксфолиант (AHA/BHA 2-3 раза/нед)
- [ ] Сыворотка (ретинол / ниацинамид / витамин C)
- [ ] Увлажняющий крем + глазной крем

## Частота процедур

| Процедура | Как часто |
|-----------|:---------:|
| AHA / BHA эксфолиация | 2-3 раза/нед, вечер |
| Ретинол | 3-4 раза/нед (начинать с 1) |
| Маска | 1-2 раза/нед |
| Скраб (физический) | 1 раз/2 нед — осторожно |
| Чистка лица (у косметолога) | 1 раз/1-2 мес |

## Трекер кожи

```
Дата: ДД.ММ.ГГГГ

Состояние (1-10): 7
  Акне: 2 (пара мелких прыщей)
  Сухость: 3 (лёгкая шелуха) - зимой
  Жирность: 5 (нормальная Т-зона)
  Краснота: 2
  Морщины / тонус: 4 (нормально для возраста)

Рутина выполнена: ✅
Сон: 7ч
Вода: 1.5 л

Заметка: ввел ретинол → лёгкое шелушение, норма
```

## Волосы и ногти

| Проблема | Возможная причина | Что делать |
|----------|-------------------|------------|
| Выпадение волос | Стресс, низкий ферритин, D, ТТГ | Анализы, цинк, D, коррекция стресса |
| Ломкие ногти | Дефицит биотина, железа | Биотин 5 мг, коллаген |
| Себорея / перхоть | Грибок, дефицит B, цинка | Цинк-пиритион шампунь, B6, цинк |
| Сухая кожа головы | Недостаток жирных кислот | Омега-3, увлажнение |
| Медленный рост | Дефицит белка, щитовидка | Белок 1.6+ г/кг, ТТГ |

---

## Тревожные сигналы — к дерматологу

- Новые родинки с изменением (цвет, форма, размер)
- Родинка >6 мм, асимметричная, с неровными краями
- Зуд, кровоточивость родинки
- Сыпь, не проходящая >2 недель
- Хронические тёмные круги под глазами (аллергия? ЖКТ?)
- Акне, не поддающееся уходу >3 мес
