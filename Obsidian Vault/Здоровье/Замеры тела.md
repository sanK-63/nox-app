# Замеры тела

## Протокол замеров

**Когда:** каждые 2 недели, утром натощак, после туалета.
**Как:** сантиметровой лентой, без натяжения, в одном и том же месте.

## Что мерить

| Замер | Где | Инструмент |
|-------|-----|-----------|
| Вес | Утром после туалета | Весы |
| Талия | Узкое место (обычно на уровне пупка) | См лента |
| Бёдра | Самая широкая часть ягодиц | См лента |
| Грудь | На уровне сосков | См лента |
| Правое плечо | Самая широкая часть | См лента |
| Правое бедро | Самая широкая часть | См лента |
| Правая голень | Самая широкая часть | См лента |
| Левое плечо | Самая широкая часть | См лента |
| Левое бедро | Самая широкая часть | См лента |
| Левая голень | Самая широкая часть | См лента |

## Прогресс-фото

**График:** каждые 4 недели.
**Формат:**
```
📍 Фронт (прямо)
📍 Спина (руки по швам)
📍 Профиль (слева, справа)
📍 Расслабленно + напряжённо

Условия:
  — То же освещение
  — То же время (утро, натощак)
  — Те же позы
  — Без фильтров / позёрства
```

| Висцеральный жир | X | <9 | — |

**Замечание:** BIA неточен (±3-4% жира). Смотреть динамику, а не абсолют.
