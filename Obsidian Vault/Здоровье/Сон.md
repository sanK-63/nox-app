## Индекс качества сна (PSQI — адаптированный)

Оценка за последний месяц:

| Параметр | Вопрос | Балл |
|----------|--------|:----:|
| 1. Длительность | Среднее часов сна | __ч = __б (0: >7ч, 1: 6-7, 2: 5-6, 3: <5) |
| 2. Засыпание | Минут до засыпания | <15=0 / 16-30=1 / 31-60=2 / >60=3 |
| 3. Пробуждения | Раз ночью | 0=0 / 1=1 / 2=2 / 3+=3 |
| 4. Эффективность | (время сна / время в постели) × 100 | >85%=0 / 75-84=1 / 65-74=2 / <65=3 |
| 5. Самочувствие днём | Сонливость (0-3) | Нет=0 / лёгкая=1 / средняя=2 / сильная=3 |
| **ИТОГО** | | **__ /15** |

**Норма:** <5. **Проблемы:** >5. **Бессонница:** >10.

## Нормы сна

| Возраст | Часов |
|---------|:-----:|
| Взрослые (18-64) | 7-9 |
| Пожилые (65+) | 7-8 |

**Короткий сон (<6ч):** +30% риск ожирения, диабета, инфаркта

## Фазы сна

```
Засыпание (15м) → NREM (лёгкий) → NREM (глубокий) → REM (быстрый)
                                ↓
                           Цикл 90 минут
                           Повтор 4-6 раз за ночь
```

| Фаза | Что происходит | % ночи |
|------|---------------|:------:|
| NREM 1 | Засыпание | 5% |
| NREM 2 | Лёгкий сон — тело расслабляется | 45-55% |
| NREM 3 | Глубокий сон — восстановление | 15-25% |
| REM | Сновидения, обработка памяти | 20-25% |

## Трекер сна

```
Дата: ДД.ММ.ГГГГ
Лёг: 23:00
Заснул: 23:15
Проснулся: 07:00
Встал: 07:15
Итого сон: 7ч 45м
Качество (1-10): 8
Заметка: лёг вовремя, не пил кофе после 16
```

## Нормализация сна — протокол

| Что делать | Когда |
|-----------|-------|
| Вставать в одно время | Каждый день (даже в выходные) |
| Без телефона за 30-60м | Синний свет подавляет мелатонин |
| Кофеин — до 14:00 | Период полураспада кофеина 5-6ч |
| Еда — за 2-3ч до сна | Пищеварение мешает |
| Спорт — не позже 20:00 | Адреналин мешает засыпанию |
| Алкоголь — минимум | Ухудшает качество сна |
| Температура 18-20°C | Жара мешает глубокому сну |
| Тёмная комната | Свет гасит мелатонин |

## Челлендж: неделя здорового сна

- [ ] День 1: без телефона за час до сна
- [ ] День 2: +лечь в 23:00
- [ ] День 3: +без кофеина после 14
- [ ] День 4: +проветрить комнату
- [ ] День 5: +тёмные шторы
- [ ] День 6: +встать без кнопки snooze
- [ ] День 7: анализ — что изменилось

## Циркадные ритмы — как синхронизировать

```
Главные якоря циркадного ритма:
  🌅 06:00-07:30 — солнечный свет (сброс мелатонина)
  🏃 08:00-10:00 — активность (сигнал "день")
  ☀️ 12:00-14:00 — максимум света (пик кортизола, энергия)
  🌇 18:00-19:00 — закат (начало выработки мелатонина)
  🌙 21:00-22:00 — минимум света (мелатонин растёт)
  🛌 22:00-23:00 — сон
```

### Практики для циркадного здоровья
- **Утро:** 5-30 мин на улице (даже в облачно) — синий свет
- **День:** перерывы на улицу каждые 2 ч
- **Вечер:** тёплый свет (лампы 2700K), диммер
- **Экраны:** f.lux / Night Shift (1800K после заката)
- **Очки:** блокирующие синий свет (желтые/оранжевые) — за 1-2 ч до сна

## Связь сна с другими аспектами

| Аспект | Влияние недосыпа |
|--------|-----------------|
| Иммунитет | ↓ NK-клетки на 70% при <6ч |
| Вес | ↑ грелин (голод), ↓ лептин (насыщение) |
| Тестостерон | ↓ на 10-30% при <5ч |
| Инсулин | ↑ риск диабета 2 типа |
| Кожа | ↑ кортизол → ↓ коллаген |
| Фокус | ↓ когнитивные функции на 30-50% |
| Настроение | ↑ тревога, ↓ эмоциональная регуляция |
