# КБЖУ — расчёты

## Формулы

### Базовый обмен (BMR)

**Mifflin-St Jeor** (наиболее точная для обычных людей):

```
Мужчины:   BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст + 5
Женщины:   BMR = 10 × вес(кг) + 6.25 × рост(см) − 5 × возраст − 161
```

**Harris-Benedict** (устаревшая, но всё ещё используется):

```
Мужчины:   BMR = 88.36 + 13.4 × вес + 4.8 × рост − 5.7 × возраст
Женщины:   BMR = 447.6 + 9.25 × вес + 3.1 × рост − 4.33 × возраст
```

### Суточная норма калорий (TDEE)

```
TDEE = BMR × коэффициент активности
```

| Активность | Коэфф. | Описание |
|-----------|:------:|----------|
| Минимальная | 1.2 | Сидячая работа, нет спорта |
| Лёгкая | 1.375 | 1-3 тренировки в неделю |
| Средняя | 1.55 | 3-5 тренировок в неделю |
| Высокая | 1.725 | 6-7 тренировок в неделю |
| Экстремальная | 1.9 | Физическая работа + спорт каждый день |

### Цель по калориям

| Цель | Формула |
|------|---------|
| Поддержание | TDEE × 1.0 |
| Мягкий дефицит (похудение) | TDEE × 0.85 |
| Дефицит (активное похудение) | TDEE × 0.75 |
| Мягкий профицит (набор массы) | TDEE × 1.1 |
| Профицит (активный набор) | TDEE × 1.2 |

## Нормы БЖУ

| Нутриент | На кг веса | На % калорий | 1 г даёт |
|----------|:----------:|:------------:|:--------:|
| Белки | 1.6-2.2 г (активным до 2.5) | 20-30% | 4 ккал |
| Жиры | 0.8-1.2 г | 25-35% | 9 ккал |
| Углеводы | остаток | 40-55% | 4 ккал |

## Примеры расчёта

### Мужчина, 30 лет, 80 кг, 180 см, 3 тренировки/нед

```
BMR = 10×80 + 6.25×180 − 5×30 + 5 = 800 + 1125 − 150 + 5 = 1780 ккал
TDEE = 1780 × 1.375 = 2448 ккал

На поддержание:   ~2450 ккал
  Белки: 80×2.0 = 160 г (640 ккал, 26%)
  Жиры:  80×1.0 = 80 г  (720 ккал, 29%)
  Углеводы: (2450−640−720)/4 = 273 г (45%)

На похудение:     ~2080 ккал (TDEE × 0.85)
  Белки: 80×2.0 = 160 г (640 ккал, 31%)
  Жиры:  80×0.9 = 72 г  (648 ккал, 31%)
  Углеводы: (2080−640−648)/4 = 198 г (38%)
```

### Женщина, 28 лет, 60 кг, 165 см, лёгкая активность

```
BMR = 10×60 + 6.25×165 − 5×28 − 161 = 600 + 1031 − 140 − 161 = 1330 ккал
TDEE = 1330 × 1.375 = 1829 ккал

На поддержание:   ~1830 ккал
  Белки: 60×1.8 = 108 г (432 ккал, 24%)
  Жиры:  60×1.0 = 60 г  (540 ккал, 30%)
  Углеводы: (1830−432−540)/4 = 215 г (46%)
```

## Как считать быстро

```python
# 1. BMR (Mifflin-St Jeor)
def bmr(weight_kg, height_cm, age_years, male=True):
    if male:
        return 10 * weight_kg + 6.25 * height_cm - 5 * age_years + 5
    return 10 * weight_kg + 6.25 * height_cm - 5 * age_years - 161

# 2. TDEE
def tdee(bmr, activity=1.375):
    return round(bmr * activity)

# 3. КБЖУ под цель
def macros(tdee, weight_kg, goal='maintain'):
    mult = {'deficit': 0.75, 'soft_deficit': 0.85,
            'maintain': 1.0, 'soft_surplus': 1.1, 'surplus': 1.2}
    kcal = round(tdee * mult[goal])
    protein = round(weight_kg * 2.0)  # г
    fat = round(weight_kg * 1.0)      # г
    carbs = round((kcal - protein*4 - fat*9) / 4)  # г
    return kcal, protein, fat, carbs

# Пример
b = bmr(80, 180, 30, male=True)
t = tdee(b, 1.375)
k, p, f, c = macros(t, 80, 'soft_deficit')
print(f"{k} ккал, {p}г белка, {f}г жира, {c}г углеводов")
```
