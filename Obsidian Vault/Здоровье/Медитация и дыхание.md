# Медитация и дыхание

Техники осознанности, дыхательные практики, трекер регулярности.

---

## Зачем

| Эффект | Доказано |
|--------|----------|
| Снижение тревоги | + |
| Улучшение фокуса | + |
| Повышение эмоциональной регуляции | + |
| Снижение кортизола | + |
| Улучшение качества сна | + |
| Снижение давления | + |

Минимальная эффективная доза: **10 мин в день** / 5 из 7 дней в неделю.

## Техники медитации

### 1. Mindfulness (осознанность)
```
Сядь прямо, закрой глаза.
Фокус на дыхании (вдох/выдох).
Мысли приходят → отметил → вернулся к дыханию.
Без оценки, без борьбы.

Старт: 5 мин → 10 → 20 мин.
```

### 2. Body Scan (сканирование тела)
```
Лёжа. Внимание идёт от макушки до пальцев ног:
  Макушка → лицо → шея → плечи → руки → грудь → живот → 
  поясница → таз → бёдра → ноги → стопы.

В каждой точке: 5-10 секунд. Отметить напряжение → расслабить.
```

### 3. Loving-Kindness (метта)
```
Повторять про себя:
  "Пусть я буду счастлив. Пусть я буду здоров."
  "Пусть {имя близкого} будет счастлив."
  "Пусть все существа будут счастливы."
```

### 4. Визуализация
```
Представить: луч света/тепла входит через макушку,
проходит по позвоночнику, заполняет тело.
Или: спокойное место (лес, пляж, гора) — детали.
```

## Дыхательные техники

### 4-7-8 (релаксация)
```
Вдох носом — 4 сек
Задержка — 7 сек
Выдох ртом — 8 сек
Повтор: 4-8 циклов
Эффект: успокаивает НС, засыпание
```

### Wim Hof (энергия / иммунитет)
```
30 циклов форсированного дыхания:
  Глубокий вдох → выдох (без паузы)
После 30 циклов: выдох → задержка (макс) → вдох 
Повтор: 3-4 раунда
⚠️ Не делать на полный желудок, не делать в воде
```

### Box breathing (фокус / стресс)
```
Вдох — 4 сек
Задержка — 4 сек
Выдох — 4 сек
Задержка — 4 сек
Повтор: 2-5 мин
Используют: спецназ, программисты, трейдеры
```

### Капалабхати (бодрость утром)
```
Резкие выдохи животом (пассивный вдох):
  1 цикл/сек, 20-30 циклов → пауза → 2-3 раунда
Эффект: разогрев, массаж внутренних органов
```

### Когерентное дыхание (heart coherence)
```
Вдох — 5.5 сек
Выдох — 5.5 сек
(6 дыханий в минуту — оптимальная частота)
Эффект: синхронизация ритмов сердца и дыхания
```
