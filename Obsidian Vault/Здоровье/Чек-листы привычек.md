# Чек-листы привычек

## Ежедневные

### Утро

- [ ] Проснулся без snooze
- [ ] Стакан воды
- [ ] Зарядка / растяжка (5-10 мин)
- [ ] Завтрак с белком
- [ ] Заправил кровать

### День

- [ ] Вода 1.5-2 л
- [ ] Овощи в каждый приём
- [ ] Белок ≥ 1.6 г/кг
- [ ] Не пил сахарные напитки
- [ ] 10 000+ шагов
- [ ] Перекус полезный (орехи/фрукты/творог)

### Вечер

- [ ] Ужин за 3 ч до сна
- [ ] Без телефона за 30 мин до сна
- [ ] Записал питание в дневник
- [ ] Вечерняя растяжка (5-10 мин)
- [ ] Лёг до 00:00 / 23:00

## Еженедельные

- [ ] Рыба ≥ 2 раза
- [ ] Красное мясо ≥ 1 раз
- [ ] Тренировки ≥ 3 раза
- [ ] Контрольный замер (вес + объёмы)
- [ ] План меню на следующую неделю
- [ ] Продукты закуплены

## Прогресс привычек (шаблон на месяц)

| Активность | Шагов/день |
|-----------|:----------:|
| Сидячая работа | 3000-5000 |
| Норма | 7000-10000 |
| Активный | 10000-15000 |
| Очень активный | 15000+ |
