# Осанка и здоровье спины

Коррекция осанки, профилактика болей в спине и шее, упражнения.

---

## Почему это важно

| Проблема | Последствия |
|----------|------------|
| Сутулость (верхний перекрёстный синдром) | Боль в шее, головные боли, зажатые плечи |
| Передний наклон таза (нижний перекрёстный) | Боль в пояснице, выпирающий живот |
| Сколиотическая осанка | Асимметрия, зажимы, дискомфорт |
| Круглые плечи | Ограничение дыхания (грудная клетка сжата) |

---

## Тест осанки (стена)

```
Встать спиной к стене:
  — Затылок, лопатки, ягодицы, пятки касаются стены
  — Шея: если подбородок задирается — слабые мышцы шеи
  — Поясница: если >1 ладони проходит — гиперлордоз
  — Плечи: если не касаются стены — круглые плечи
```

---

## Трекер осанки (ежедневно)

```
Дата: ДД.ММ.ГГГГ

Боль в спине (1-10): 2  (0 = нет, 10 = невыносимо)
Боль в шее (1-10):    1
Боль в пояснице (1-10): 3

Осознанность осанки (1-10): 5
  (насколько часто вспоминал и поправлял)

Упражнения на сегодня:
  - [ ] Разгибание грудного отдела (на валике) — 2 мин
  - [ ] "Дверной растяжка" для груди — 1 мин × 2
  - [ ] Подтягивание лопаток (scapula pulls) — 15 раз
  - [ ] Планка — 60 сек
  - [ ] Ягодичный мостик — 15 раз

Заметка: 6ч за компом → зажата шея к вечеру
```

---

## Ежедневный минимум (10 мин)

### 1. Разблокировать грудной отдел
```
Валик (или свёрнутое полотенце) под середину спины.
Руки за голову. Лежать 2 мин.
Дышать глубоко — грудная клетка раскрывается.
```

### 2. Растяжка груди (“дверная”)
```
Встать в дверном проёме, руки по сторонам под 90°.
Подать грудь вперёд. 30-60 сек × 2.
```

### 3. Сведение лопаток
```
Стоя/сидя. Свести лопатки вместе + опустить вниз.
Задержать 3-5 сек. 15 повторений.
```

### 4. Наклон таза (pelvic tilt)
```
Лёжа на спине, ноги согнуты.
Подкрутить таз вперёд (поясница прижимается к полу).
10-15 повторений, задержка 3-5 сек.
```

### 5. Ягодичный мостик
```
Лёжа, ноги согнуты. Поднять таз вверх, сжать ягодицы.
15-20 повторений.
```

## Рабочее место (эргономика)

| Что | Как |
|-----|-----|
| Монитор | Верхняя треть на уровне глаз, ~1 рука от себя |
| Стул | Поясничный валик, бёдра под 90°, стопы на полу |
| Клавиатура | Локти под 90°, запястья прямые |
| Перерывы | Каждые 45-60 мин — встать, пройтись, потянуться |
| Экран | На уровне глаз — чтобы не опускать голову |

---

## "Экранная шея" (text neck)

Каждый градус наклона головы = нагрузка на шею:

| Наклон | Нагрузка |
|:------:|:--------:|
| 0° (прямо) | 5 кг (голова) |
| 15° | 12 кг |
| 30° | 18 кг |
| 45° | 22 кг |
| 60° | 27 кг |

**Решение:** поднять телефон/монитор на уровень глаз.

---

## Коррекция гиперлордоза (поясница)

```
Если: стоит / лежит на спине — сильный прогиб в пояснице
Причина: слабый пресс + зажатые сгибатели бедра + слабые ягодицы

Что делать:
  ❌ Не качать поясницу (она и так в гипертонусе)
  ✅ Качать пресс (планка, roll-up, вакуум)
  ✅ Растягивать сгибатели бедра (выпад)
  ✅ Качать ягодицы (мостик, ягодичный мост на одной ноге)
```
