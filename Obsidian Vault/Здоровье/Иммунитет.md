# Иммунитет

Укрепление иммунной системы, сезонные меры, частые болезни — трекинг.

---

## База: что реально работает

| Практика | Эффективность | Доказано? |
|----------|:------------:|:----------:|
| Сон ≥7ч | +++ | Да — ключевой фактор |
| Умеренная активность | ++ | Да — лимфоток |
| Витамин D (нормальный уровень) | ++ | Да — от 2000 МЕ/день |
| Цинк ← 25 мг (при первых симптомах) | ++ | Да — снижает длительность |
| Витамин C (500-1000 мг/день) | + | Умеренно, лучше из еды |
| Снижение стресса | ++ | Да — кортизол подавляет |
| Контрастный душ | + | Мнения разделились |
| Чеснок/имбирь | + | Слабая доказательная база |

## Трекер болезней

```
Дата начала: ДД.ММ.ГГГГ
Симптомы: насморк, горло, 37.2

Дни:
  День 1: начало, температура 37.2, слабость
  День 2: горло болит, насморк, температура 36.8
  День 3: насморк, кашель
  День 4: всё прошло, осталась усталость

Что делал: цинк 25 мг, С 1000 мг, чай с имбирём, сон 9ч
Вывод: легче, чем в прошлый раз — возможно, цинк помог
```

## Профилактика по сезонам

### Осень / Зима (пик ОРВИ)
- [ ] Витамин D: 3000-5000 МЕ/день (окт-апр)
- [ ] Цинк: 15-25 мг/день (курс 2 мес)
- [ ] Увлажнитель воздуха — сухой воздух снижает местный иммунитет
- [ ] Гигиена: руки после улицы, не трогать лицо
- [ ] Промывание носа (аквамарис / физраствор)
- [ ] Одеваться по погоде — переохлаждение снижает защиту

### Весна
- [ ] Анализ крови (ферритин, D, ТТГ, Т4)
- [ ] Антигистаминные — если сезонная аллергия
- [ ] Добавка D — ещё актуально

### Лето
- [ ] Солнце 15-30 мин/день (без СПФ) — витамин D
- [ ] Купание в открытых водоёмах — не забывать про защиту
- [ ] Овощи/фрукты сезонные — максимум витаминов

## Часто болею? — проверить

| Причина | Что проверить |
|---------|--------------|
| Дефицит D | 25-OH витамин D |
| Дефицит железа | Ферритин, гемоглобин |
| Стресс / перетрен | Кортизол, пульс в покое |
| Щитовидка | ТТГ, Т4 |
| Хроническое воспаление | СРБ (hs-CRP) |
| Дисбактериоз | Копрограмма |

---

## "Челлендж": месяц без болезней

- [ ] Сон ≥7ч каждый день
- [ ] D 3000+ МЕ/день
- [ ] Цинк 25 мг/день
- [ ] Нет сахара (сахар ослабляет иммунитет на 2-3ч)
- [ ] 10 000 шагов / день
- [ ] Умывание холодной водой утром
- [ ] Никакого алкоголя
