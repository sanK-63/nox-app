# Статистика веса

Дневник веса + график прогресса.

## Анализ тренда (важнее, чем цифра на весах)

Вес колеблется ±1-2 кг в день из-за воды, гликогена, соли, ЖКТ.
**Смотреть нужно скользящее среднее за 7-14 дней.**

```
Пример:
  День:  1  2  3  4  5  6  7
  Вес:   80 81 79 80.5 78.5 80 79
  Средн:               80.0 79.9 79.8 79.7 79.6

Реальный тренд: −0.4 кг/нед — ✅ норм
```

### Нормы изменения веса

| Цель | В неделю | В месяц |
|------|:--------:|:-------:|
| Мягкое похудение | 0.2-0.5 кг | 1-2 кг |
| Активное похудение | 0.5-1.0 кг | 2-4 кг |
| Поддержание | ±0.2 кг | ±0.5 кг |
| Набор массы | 0.2-0.5 кг | 1-2 кг |

## ИМТ (Индекс массы тела)

```
ИМТ = вес(кг) / рост(м)²
```

| ИМТ | Категория |
|:---:|-----------|
| <18.5 | Дефицит массы тела |
| 18.5-24.9 | Норма |
| 25-29.9 | Избыточная масса |
| 30-34.9 | Ожирение I степени |
| 35+ | Ожирение II+ степени |

## Что влияет на вес

```
Ежедневные колебания: ±1-2 кг — норма
  Влияет:
    ▸ Вода в организме (соль → задержка)
    ▸ Содержимое ЖКТ
    ▸ Гликоген (углеводы → запас воды)
    ▸ Цикл (гормоны)

Способы уменьшить шум:
  ▸ Взвешиваться утром, после туалета, натощак
  ▸ Смотреть тренд за неделю, а не одно взвешивание
  ▸ HappyScale / Libra — приложения сглаживают график
```

## Когда вес не снижается (плато)

| Причина | Что делать |
|---------|-----------|
| Задержка воды (соль, цикл) | Подождать 1-2 нед |
| Ослабленный дефицит (недосчитываешь) | Пересчитать КБЖУ, взвешивать еду |
| Метаболическая адаптация | Refeed / diet break (1-2 нед в поддерживающих) |
| Рост мышц | Если тренировки + вес стоит (выглядишь лучше) |
| Недосып / стресс | Наладить сон — кортизол мешает жиросжиганию |
