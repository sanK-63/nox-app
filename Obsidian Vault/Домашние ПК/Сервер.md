# Сервер 4U

**Прозвище:** Сервер  
**Назначение:** Виртуализация, NAS, игровой сервер (Minecraft)  
**OS:** Proxmox VE 8.x  
**Расположение:** Дома, в стойке

---

## Конфигурация

| Компонент | Модель | Характеристики |
|-----------|--------|----------------|
| Корпус | 4U Rackmount | Серверный, полноразмерные платы |
| Процессор | Intel Core i3-2130 | 2C/4T, 3.4 GHz, Sandy Bridge, LGA1155 |
| Материнская плата | LGA1155 (H61/B75) | 2×DIMM DDR3, SATA 3Gb/s, PCIe 2.0 |
| RAM | 4 GB DDR3 | 2×2 GB, 1333 MHz |
| SSD | 120 GB | SATA, система Proxmox |
| HDD #1 | 1 TB | SATA, ZFS Mirror (pool) |
| HDD #2 | 1 TB | SATA, ZFS Mirror (pool) |
| GPU | NVIDIA GTX 1050 Ti 4 GB | Не используется |
| Сеть | Realtek / Intel | 1 Gbps |
