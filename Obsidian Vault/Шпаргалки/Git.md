# Git — Шпаргалка

## Основное

```bash
git status                    # состояние
git add .                     # добавить всё
git commit -m "message"       # коммит
git push                      # отправить
git pull                      # забрать
```

## Ветки

```bash
git branch                    # список веток
git checkout -b new-branch    # создать и переключиться
git merge branch              # слить ветку
```
