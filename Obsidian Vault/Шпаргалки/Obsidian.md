# Obsidian Cheatsheet

## Ссылки

| Синтаксис | Результат |
|-----------|-----------|
| `[[Заметка]]` | Ссылка на заметку |
| `[[Заметка\|Текст]]` | Ссылка с кастомным текстом |
| `[[Заметка#Заголовок]]` | Ссылка на заголовок |
| `[[Заметка#^id]]` | Ссылка на блок с id |
| `![[Изображение.png]]` | Вставка изображения |
| `[Текст](url)` | Внешняя ссылка |

## Форматирование

| Синтаксис | Результат |
|-----------|-----------|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `==выделение==` | ==выделение== |
| `~~зачёркнуто~~` | ~~зачёркнуто~~ |
| `> цитата` | Цитата |
| ``` ``код`` ``` | `код` |
| `- [ ] задача` | Чекбокс |

## Теги

`#Тег` или `#Тег/Подтег` — в любом месте заметки. Graph View группирует по тегам.

## Hotkeys

- `Ctrl+P` — палитра команд
- `Ctrl+O` — открыть заметку
- `Ctrl+N` — новая заметка
- `Ctrl+Shift+F` — поиск по всем заметкам
- `Ctrl+E` — просмотр графа
