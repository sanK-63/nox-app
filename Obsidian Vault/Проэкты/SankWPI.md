# SankWPI — Windows Post-Install Wizard

> **Связанные проекты:** [[Nox Task Manager]], [[Kinetic Launcher|Kinetic Launcher]], [[KineticCraft Server|KineticCraft Server]], [[knm.pp.ua]], [[Home Server]], [[Playlist Adder]] — другие проекты автора (Sank)

## Обзор

**SankWPI** — компактный мастер установки Windows-программ после переустановки системы.  
Единый `.exe` файл: запускаешь — 5 секунд киношной ASCII-загрузки, затем появляется окошко, где выбираешь что ставить и жмёшь «Начать работу». Всё ставится само через `winget`.

## Технологии

| Технология | Назначение |
|------------|------------|
| **PowerShell 5.1** | Весь код — язык логики, работа с Win32 API, WPF-окно |

| **PS2EXE** (v1.0.18) | Компилятор `.ps1` → `.exe`. Упаковывает скрипт + рантайм в один файл |
| **WinGet** | Встроенный пакетный менеджер Windows 10/11. `winget install <id>` |
| **Win32 API** | Используется для получения и скрытия консольного окна через `user32.dll` / `kernel32.dll` |
| **JSON** | Формат конфига со списком программ (категории, ID, тип установки) |

## Как это работает

### 1. Запуск (`setup.ps1` → `SankWPI.exe`)

PS2EXE компилирует скрипт в `.exe`:
- Флаг `-requireAdmin` — манифест запрашивает повышение (UAC-диалог при запуске)
- `-iconFile` — задаёт иконку исполняемого файла
- Результат — портативный `.exe`, не требующий PowerShell для запуска

### 2. Console Boot Sequence (кино)

```
1. Получается HWND консоли через GetConsoleWindow()
2. Устанавливается светло-серый фон + белый текст
3. Выводятся 23 строки «загрузки» (инициализация модулей, драйверов и т.п.) — по 50 мс каждая
4. Пауза 400 мс → очистка консоли
5. Выводится ASCII-арт «SankWPI» (белым на чёрном)
6. Пауза 2.5 сек → принудительный Flush()
7. Консоль скрывается через ShowWindow(hWnd, 0)
```

Зачем: чисто эстетика — ощущение «дорогого» инструмента, как в кино.

### 3. WPF GUI (Wizard)

- **Шаг 1–5**: категории программ (Разработка, Утилиты, Игры, Тесты, AI) — чекбоксы в один столбец
- **Шаг 6**: твики Windows (тёмная тема, скрытые файлы, телеметрия и т.д.)
- Кнопка **«Далее»** / **«Начать работу»** — одна на весь экран
- Прогресс бар + лог установки — скрыты до старта

Элементы интерфейса объявлены в XAML и загружаются через `XamlReader.Load()`.

### 4. Установка

- Каждый выбранный элемент обрабатывается в `Runspace` (фоновый поток)
- UI обновляется через `Dispatcher` + таймер (`0x44C`)
- Типы установки:
  - `winget` — `winget install <id>`
  - `custom_download` — `Invoke-WebRequest` + тихий запуск
  - `custom_download_manual` — открывает браузер
  - `tweak` — правка реестра Windows

## Ключевые архитектурные моменты

### `$script:` префикс в обработчиках событий

PowerShell создаёт локальную копию переменной при записи в блоке события.  
Без `$script:currentStep` изменения шага в кнопке «Далее» не сохранялись бы.

### Встроенный JSON с внешним перекрытием

```powershell
$embeddedConfig = @'...'@   # жёстко в скрипте
if (Test-Path config.json)  # внешний приоритет (для разработки)
```

### Консоль без `-noConsole`

PS2EXE по умолчанию создаёт консольное приложение. Это нужно для ASCII-сцены.  
После показа скрипт сам прячет окно — не надо жертвовать графической оболочкой.

### `[Console]::WriteLine` вместо `Write-Host`

`Write-Host` в скомпилированном PS2EXE может буферизоваться.  
Прямой вызов `[Console]::WriteLine()` + `Out.Flush()` гарантирует мгновенный вывод.

## Сборка

```powershell
# Из PowerShell (админ):
$docs = [Environment]::GetFolderPath("MyDocuments")
Import-Module (Join-Path $docs "WindowsPowerShell\Modules\ps2exe") -Force
Invoke-ps2exe -InputFile setup.ps1 `
              -OutputFile SankWPI.exe `
              -IconFile image.ico `
              -requireAdmin
```
