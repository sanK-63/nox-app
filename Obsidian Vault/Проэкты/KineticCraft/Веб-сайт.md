## Стек

| Компонент | Технология | Роль |

## Архитектура

```
Minecraft Server
    ↕ KineticBridge (plugin)
Supabase (KineticCraft-DB)
    ↕ API (прямой доступ из браузера)
GitHub Pages (статический сайт)
    ↕ GitHub Actions (CI/CD)
GitHub (репозиторий)
```

### CI/CD Pipeline
1. Пуш в `main` → триггер GitHub Actions
2. `build` — компиляция фронтенда
3. `report-build-status` — проверка ошибок
4. `deploy` — публикация на GitHub Pages

---

## Безопасность: RLS (Row-Level Security)

Так как сайт на GitHub Pages обращается к [[Supabase]] напрямую из браузера:

- **Обязательно** включать RLS на таблицах в `public`
- Без RLS — любой может читать/писать данные, зная URL проекта
- Для публичных данных (онлайн, статус) — только **Read-Only** (SELECT)
