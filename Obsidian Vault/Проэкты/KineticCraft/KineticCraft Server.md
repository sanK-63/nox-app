# KineticCraft

## Состав проекта

| Компонент | Описание |
|-----------|----------|
| [[Веб-сайт]] | Фронтенд + интеграция через KineticBridge + Supabase |
| **Серверная сборка** | Моды, конфиги, оптимизация (ядро проекта) |

---

## Стек оптимизации

| Мод | Назначение |
|-----|------------|
| **ModernFix** | Оптимизация RAM + ускорение запуска |
| **FerriteCore** | Снижение затрат памяти на текстуры |
| **Radium** (форк Lithium) | Оптимизация серверной логики, ИИ, чанков |
| **Starlight** | Замена движка освещения — без лагов при генерации |
| **Krypton FNP** | Оптимизация сети — снижение пинга и трафика |

## Геймплейные направления

### Индустрия и автоматизация

| Мод | Роль |
|-----|------|
| **Create** + аддоны (New Age, Steam Rails, Enchantment Industry) | Кинетическая автоматизация, поезда, опыт |
| **Mekanism** | Многоблочные машины, переработка руд (x5), энергия |
| **Immersive Engineering** | Ретро-индустрия: ЛЭП, провода, заводы |
| **AE2** + Applied Mekanistics, Applied Botanics | Цифровое хранение, автокрафт, интеграция с газами и маной |

### Магия

| Мод | Роль |
|-----|------|
| **Ars Nouveau** | Кастомные заклинания через глифы |
| **Botania** | Техническая магия: сила цветов и маны |
| **Forbidden & Arcanus** | Тёмная магия, ритуалы, артефакты |

### Мир и исследования

| Мод | Роль |
|-----|------|
| **Blue Skies** | Два новых измерения с данжами и боссами |
| **L_Enders_Cataclysm** | Эндгейм-боссы (Невежество, Вестник пустоты) |
| **Alex's Mobs** | 80+ видов существ |
| **MineColonies + MCA** | Градостроительство, найм жителей |

## Экономика и системы

| Термин | Описание |
|--------|----------|
| **FTB Quests** (индивидуальный прогресс) | Задачи и награды независимо для каждого игрока |
| **Chunky** (предгенерация чанков) | Принудительная генерация мира для стабильного TPS |
| **Lootr** (изолированный лут) | Уникальный лут в сундуках для каждого игрока |
| **Lightman's Currency** | Внутриигровая валюта (монеты) для торговли |
