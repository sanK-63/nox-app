# knm.pp.ua

**Статус:** `Активный`  
**Тип:** Персональный веб-сайт / Инфраструктурный узел  
**Домен:** [knm.pp.ua](https://knm.pp.ua)  
**Регистратор:** NIC.UA (23 марта 2026)

---

## Инфраструктура

| Компонент | Сервис | Назначение |
|-----------|--------|------------|
| **DNS** | NIC.UA | A/AAAA/CNAME записи для поддоменов |
| **Фронтенд** | [[Vercel]] | Статические страницы и SPA |
| **Бэкенд** | **Render** | Серверные приложения |
| **Контейнеры** | **Railway** | Быстрый деплой контейнеризированных сервисов |
| **БД / Auth** | [[Supabase]] (PostgreSQL) | Данные, авторизация, API |

---

## Архитектура

```
knm.pp.ua
├── www (Vercel) — основной сайт
├── api.* (Render) — бэкенд-сервисы
├── app.* (Railway) — контейнерные приложения
└── pg.* (Supabase) — базы данных
```

### CI/CD
GitHub → автоматический деплой на Vercel / Render при пуше в `main`.

### Поддомены (перспектива)
- `mc.knm.pp.ua` — дашборд [[KineticCraft Server|KineticCraft Server]]
- `api.knm.pp.ua` — API для бота / сервисов
- `dev.knm.pp.ua` — тестовый стенд
