# Go

**Тип:** Systems programming language, compiled, garbage-collected  
**Владелец:** Google  
**Релиз:** 1.0 в 2012  

## Ключевые особенности

- **Goroutines** — лёгкие потоки (2KB стек), `go func()` для конкурентности
- **Channels** — передача данных между горутинами (CSP)
- **Fast compilation** — секунды вместо минут
- **Static linking** — один бинарник без зависимостей
- **Garbage collection** — низкая latency, optimised для веба
- **No generics** (до 1.18) → теперь generics есть, но ограниченные
- **`defer`** — отложенный вызов для cleanup

| ent / GORM | ORM |

| Docker / Kubernetes | Написаны на Go |
| Hugo | Статический генератор сайтов |
| Prometheus | Мониторинг |

## Когда использовать

- **Микросервисы** — быстрая компиляция, малый размер бинарника, встроенная конкурентность
- **CLI-инструменты** — один бинарник, кроссплатформенность
- **Сетевые сервисы** — HTTP/gRPC из коробки
- **DevOps-инструменты** — Docker, k8s, Terraform написаны на Go

**Не подходит для:** GUI-приложений, систем реального времени, ML/AI (нет экосистемы), эмбеддед.
