# Архитектура LLM

## Transformer — основа всех современных LLM

Бумага: *"Attention Is All You Need"* (Vaswani et al., 2017)

### Схема работы

```
Токены → Embedding → Positional Encoding
                          ↓
             ┌──────────────────────┐
             │   Multi-Head Self-   │
             │     Attention        │
             └──────────────────────┘
                          ↓
             ┌──────────────────────┐
             │   Feed-Forward NN    │
             └──────────────────────┘
                     × N layers
                          ↓
                     LM Head → логиты → softmax → токены
```

### Attention (внимание)

`Attention(Q,K,V) = softmax(QK^T / √d_k) · V`

- **Q** (Query) — что ищем
- **K** (Key) — с чем сравниваем
- **V** (Value) — что выдаём

Для каждого токена считаем "важность" остальных токентов в последовательности. Размер O(n²) — главный bottleneck.

### Multi-Head Attention

Несколько параллельных attention-слоёв с разными весами — модель учится смотреть на разные аспекты текста одновременно.

### Архитектурные вариации attention

| Вариант | Память | Скорость | Модели |
|---------|--------|----------|--------|
| **MHA** (Multi-Head) | Высокая | База | GPT-2, BERT |
| **MQA** (Multi-Query) | Низкая | Быстро | Falcon, PaLM |
| **GQA** (Grouped-Query) | Средняя | Сбалансирован | Llama 2/3/4, Mistral, GPT-4 |
| **MLA** (Multi-head Latent) | Очень низкая | Быстро | DeepSeek-V3 |
| **Sliding Window** | O(n·w) | Быстро | Mistral, Gemma 2 |
| **Hybrid** (SW + Full) | Адаптивная | Сбалансирован | Qwen 3.5+, Gemini 3 |

GQA — стандарт для всех современных моделей. Группы query heads разделяют общие key/value heads.

## Типы LLM

| Тип | Примеры | Особенности |
|-----|---------|------------|
| **Decoder-only** | GPT-4, Claude, Llama | Авторегрессивная генерация, лучшие для текста |
| **Encoder-only** | BERT, RoBERTa | Понимание текста (классификация, NER) |
| **Encoder-Decoder** | T5, BART | Seq2seq задачи (перевод, суммаризация) |

## Ключевые параметры

| Параметр | Что означает |
|----------|-------------|
| **Context window** | Макс. длина входа в токенах (4K–1M) |
| **Hidden size** | Размерность скрытого слоя (4096–8192) |
| **Layers** | Количество трансформер-блоков (32–96) |
| **Attention heads** | Голов в multi-head attention (16–64) |
| **Parameters** | Общее количество весов (7B–1.8T) |

## Токенизация

- Текст → токены (слова, части слов, символы)
- BPE (Byte-Pair Encoding), WordPiece, Unigram
- Разные токенизаторы → разное количество токенов на текст
- Пример: "Hello World" → [15496, 2159] (GPT-4)

## Архитектурные улучшения (2023-2026)

| Техника | Проблема | Решение |
|---------|----------|---------|
| **RoPE** (Rotary Position Encoding) | Positional encoding | Относительные позиции, extrapolation |
| **KV Cache** | Повторные вычисления при генерации | Кэширование K,V матриц на каждый шаг |
| **GQA** (Grouped-Query Attention) | Multi-Head требует много памяти | Группировка голов K,V |
| **MoE** (Mixture of Experts) | Полный forward дорогой | Только часть "экспертов" активируется |
| **Flash Attention** | O(n²) медленный на длинных контекстах | IO-aware, tiling в SRAM |
| **Speculative Decoding** | Генерация токенов медленная | Маленькая модель делает черновик, большая проверяет |
| **Multi-Token Prediction** | 1 токен за forward | Мета обучается предсказывать несколько токенов сразу |

### MoE (Mixture of Experts) — детально

Стандарт де-факто для масштабирования в 2026.

```
Вход
 ↓
Router (gate network) → softmax → top-K экспертов
 ↓             ↓
Эксперт A    Эксперт B     (2 из 128 активны)
 ↓             ↓
  └──────┬──────┘
         ↓
      Выход (взвешенная сумма)
```

| Модель | Всего параметров | Active | Экспертов |
|--------|:----------------:|:------:|:---------:|
| DeepSeek-V3 | 671B | 37B | 256 |
| Qwen 4 32B-A3B | 32B | 3B | — |
| Qwen 3.5 | 397B | 17B | — |
| Mistral Small 4 | 119B | 6B | 128 |
| Llama 4 Maverick | 400B | 17B | 128 |
| Grok 4 Open | ~300B | ~40B | 64 |

MoE позволяет иметь "умную" модель с маленьким активным размером — идеально для инференса.

### Positional Encoding — эволюция

| Метод | Как кодирует | Используют |
|-------|-------------|-----------|
| **Absolute** (Sinusoidal) | Позиция = синус/косинус | GPT-2, BERT |
| **Learned Absolute** | Позиция = обучаемый вектор | GPT-3 |
| **RoPE** (Rotary) | Поворот Q,K в зависимости от позиции | **Llama, Mistral, GPT-4, все современные** |
| **ALiBi** | Линейный штраф на attention | MPT, Bloom |
| **YaRN** | RoPE + scaling для длинных контекстов | Расширение окна |

### Test-Time Compute (Reasoning Models)

Отдельный класс моделей, которые "думают" перед ответом:

```
Обычная LLM:   Токен → Токен → Токен → Ответ
Reasoning LLM: Токен → ...рассуждение (CoT)... → Ответ

Потраченное на рассуждение время = test-time compute.
Чем сложнее задача → тем больше токенов на рассуждение.
```

| Модель | Тип | Механизм |
|--------|-----|----------|
| **o1/o3** (OpenAI) | Chain-of-Thought | Скрытые токены рассуждения |
| **DeepSeek-R1** | Open CoT | RL на chain-of-thought |
| **Gemini 3 Pro Thinking** | Configurable | Включается по запросу |
| **GPT-5.5 Pro** | Adaptive | Автоматически выбирает глубину |
| **Claude Opus 4.8** | Natural | Без отдельного режима |
