# Prompt Engineering

## Структура промпта

```
[System]   — роль, контекст, правила
[Examples] — few-shot (1–3 примера)
[Context]  — документы, данные (для RAG)
[Query]    — что нужно сделать
[Output]   — формат вывода (JSON, XML, код)
```

## Базовые техники

### Zero-shot
```
Переведи на русский: "Hello, World!"
```

### Few-shot (с примерами)
```
Английский → Русский
"Hello" → "Привет"
"Good morning" → "Доброе утро"
"See you later" → ?
```

### Chain-of-Thought (CoT)
```
Реши: 24 × 37
Шаг 1: 20 × 37 = 740
Шаг 2: 4 × 37 = 148
Шаг 3: 740 + 148 = 888
Ответ: 888
```

### Role prompting
```
Ты — senior Python-разработчик. Проведи code review:
```

### Structured output
```
Ответь в JSON:
{
  "название": "строка",
  "цена": число,
  "доступно": boolean
}
```

## Продвинутые техники

| Техника | Когда | Как |
|---------|-------|-----|
| **CoT** | Сложные рассуждения | "Let's think step by step" |
| **Tree-of-Thoughts** | Поиск по дереву решений | Несколько parallel CoT |
| **Self-consistency** | Усреднение нескольких ответов | Sample → majority vote |
| **ReAct** | Агентные действия | Think → Act → Observe → ... |
| **Generated Knowledge** | LLM генерирует факты перед ответом | "Generate relevant facts" |
| **EmotionPrompt** | Эмоциональный стимул | "This is very important for my career" |

## Эвристики

- **Чёткая инструкция:** "Напиши функцию" → плохо. "Напиши функцию на Python, которая принимает список чисел и возвращает отсортированный" → хорошо
- **Ограничение пространства:** Укажи формат, длину, стиль
- **Отрицательные примеры:** "НЕ используй markdown" (работает хуже позитивных)
- **Delimiters:** ```, ---, ### для отделения секций
- **Температура:** 0 для фактов, 0.7 для креатива, >1 для идей
- **Повторение:** Если не сработало → перефразируй или добавь контекст

## Common patterns

### Классификация
```
Определи тональность (positive/neutral/negative):
Текст: "{текст}"
Тональность:
```

### Извлечение
```
Извлеки из текста: имя, email, телефон.
Текст: "{текст}"
JSON:
```

### Суммаризация
```
Суммируй в 3 предложениях:
{текст}
```

### Code generation
```
Напиши TypeScript-функцию:
- название: calculateTotal
- параметры: items (массив {price, quantity})
- возвращает: число с НДС
```

## Оценка промптов

```
1. Baseline — базовый промпт
2. Variation — изменяем одну часть
3. A/B test — сравниваем на тестовом наборе
4. Iterate — повторяем
```
