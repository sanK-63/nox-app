# Экосистема инструментов LLM

Как собирать, деплоить, мониторить и агментировать LLM в 2026.

## Фреймворки для RAG и агентов

| Фреймворк | Когда | Особенности |
|-----------|-------|-------------|
| **LangChain** | Прототипы, широкий спектр | Много интеграций, но сложный API |
| **LlamaIndex** | RAG, документы | Отличный data ingestion |
| **Haystack** | Search + QA | Промышленный, стабильный |
| **Semantic Kernel** (MS) | .NET / Python | Интеграция с M365 |
| **AutoGen** (MS) | Multi-agent | Несколько агентов общаются |
| **CrewAI** | Multi-agent | Простой API для агентных команд |
| **DSPy** | Программируемые LLM | Оптимизация промптов через программирование |
| **Smolagents** (HF) | Code-agents | Агенты, которые пишут код для действий |

## Деплой и Serving

| Инструмент | Назначение | Когда |
|-----------|-----------|-------|
| **vLLM** | Высокопроизводительный инференс | Продакшн, много пользователей |
| **Ollama** | Локальный запуск | Разработка, Mac, CPU |
| **SGLang** | Структурированный вывод | JSON/код/агенты |
| **BentoML** | ML deployment | Фулстак деплой |
| **Modal** | Serverless GPU | Облачный инференс |
| **Baseten** | Serverless | Прод, простой API |
| **LlamaEdge** | Edge + Wasm | IoT, edge devices |
| **OpenRouter** | Unified API | Один API к 100+ моделям |

## Модельные хаб

Платформы для поиска и загрузки моделей:
- **Hugging Face Hub** — стандарт, 1M+ моделей
- **Ollama Library** — `ollama pull Qwen4`
- **ModelScope** (Alibaba) — азиатские модели
- **Replicate** — облачный ран

## Инструменты для конкретных задач

### Coding
- **Claude Code** (Anthropic) — CLI-агент для кодинга в терминале
- **GitHub Copilot** — автокомплит на базе GPT
- **Cursor** — IDE со встроенным AI
- **Continue** (open-source) — VS Code / JetBrains AI

### Prompt Engineering
- **Promptfoo** — A/B тестирование промптов
- **Portkey** — Gateway + Prompt management
- **LangSmith Hub** — шаринг промптов

### Fine-tuning
- **Unsloth** — 2x быстрее, меньше памяти, LoRA
- **Axolotl** — YAML-конфиги, много опций
- **LLaMA-Factory** — Web UI
- **Torchtune** — Нативный PyTorch

### Training
- **NVIDIA NeMo** — полный пайплайн
- **Megatron-LM** — 3D parallelism
- **DeepSpeed** (Microsoft) — ZeRO stages 1/2/3
- **FSDP** (PyTorch) — Fully Sharded Data Parallel
- **Horovod** — distributed training

## Агентные фреймворки

```
Классификация агентов по сложности:

Level 0: LLM без инструментов (чат)
Level 1: LLM + RAG (поиск по документам)
Level 2: LLM + function calling (API, код)
Level 3: LLM + multi-step planning (ReAct, Tree-of-Thoughts)
Level 4: Multi-agent (несколько LLM работают вместе)
Level 5: LLM + обучение (RL на инструментах)
```

### Протоколы для агентов

| Протокол | Описание |
|----------|----------|
| **MCP** (Model Context Protocol, Anthropic) | Стандарт подключения инструментов к LLM |
| **A2A** (Agent-to-Agent, Google) | Коммуникация между агентами |
| **OpenAI Agents SDK** | Сборка агентов и рутинг |
| **Function Calling** (native) | Встроенный вызов функций |
