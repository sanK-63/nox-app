# Бенчмарки LLM

Как измеряют качество LLM — и кто лидирует в июне 2026.

## Ключевые бенчмарки

### Общие знания и reasoning

| Бенчмарк | Что измеряет | Формат |
|----------|-------------|--------|
| **MMLU** | 57 предметов (школьный уровень) | Multiple choice |
| **MMLU Pro** | MMLU + более сложные вопросы | Multiple choice |
| **GPQA Diamond** | Graduate-level science (физика, химия, биология) | Multiple choice |
| **ARC-AGI-2** | Абстрактное reasoning (новые задачи) | Grid puzzles |

### Математика

| Бенчмарк | Что измеряет |
|----------|-------------|
| **GSM8K** | Математика уровня средней школы |
| **MATH** | Олимпиадная математика |
| **AIME** | Американская олимпиада (очень сложно) |

### Кодинг

| Бенчмарк | Что измеряет | Почему важен |
|----------|-------------|--------------|
| **HumanEval** | Написание функций по описанию | Классика, но насытился |
| **SWE-Bench Verified** | Реальные GitHub issues (PR должен пройти CI/CD) | **Самый важный** — коррелирует с реальной работой |
| **SWE-Bench Pro** | Ещё сложнее, multi-file changes | Вершина coding-бенчмарков |
| **Terminal-Bench** | Работа в терминале (DevOps, CI/CD) | Для агентов |

### Агенты и инструменты

| Бенчмарк | Что измеряет |
|----------|-------------|
| **MCP-Atlas** | Tool use, function calling |
| **BFCL V3** | Function calling |
| **GAIA** | Multi-step agentic задачи |

## Проблемы бенчмарков

| Проблема | Описание |
|----------|----------|
| **Data contamination** | Модель видела тест в обучении (GPT-4 → MMLU "назубок") |
| **Benchmark saturation** | HumanEval близок к 100% → больше не дискриминирует |
| **Shortcut learning** | Модель находит паттерны, а не reasoning |
| **EU vs US bias** | Бенчмарки на английском, западно-центричны |
| **Gaming** | Компании оптимизируют под конкретные тесты |

**Live benchmarks:** LMSYS Chatbot Arena (Elo, человеческие предпочтения) — лучший "честный" бенчмарк.
