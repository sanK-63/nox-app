# Введение в ML и LLM

Как подходить к ML / LLM с нуля: теория, инструменты, практика.

## ML за 5 минут

### Что такое ML

ML = программа, которая не следует правилам, а **учится** на примерах.

```
Традиционное программирование:
  Правила + Данные = Ответ

ML:
  Ответы + Данные = Правила (модель)
```

### Три столпа

| Тип | Суть | Пример для LLM |
|-----|------|----------------|
| **Supervised** | Учим по парам (вход → ответ) | Fine-tuning: промпт → идеальный ответ |
| **Unsupervised** | Ищем структуру в данных без ответов | Pretraining: LLM учит язык предсказывая следующий токен |
| **RL** (Reinforcement) | Учим через пробу/ошибку с наградой | RLHF: модель учится быть полезной через оценку человека |

### Neural Network — минимальная схема

```
Вход (текст) → [Embedding] → [Transformer блоки] → [LM Head] → Выход (токены)
                     ↑                            ↑
              Числа, понятные сети           Вероятности слов
```

Сеть = много матричных умножений с нелинейностями между ними. Размер сети = количество весов (параметров). LLM = очень большая нейросеть (7B-1.8T параметров).

## LLM — что изменилось

LLM не классический ML. Разница:

| | Классический ML | LLM |
|--|----------------|-----|
| **Данные** | Таблицы, картинки | Текст (и мультимода) |
| **Модель** | Random Forest / XGBoost / CNN | Transformer |
| **Обучение** | Часы на GPU | Месяцы на кластере (H100×10000) |
| **Использование** | `model.predict(X)` | `model.generate(prompt)` |
| **Главное** | Архитектура | Данные + масштаб |

**Ключевое открытие:** LLM понимают **контекст**, а не просто классифицируют. Одна модель делает сотни задач.

## Как работать с LLM — 5 уровней

### Уровень 1: Чат / API (без кода)

```
Ты → [промпт] → [Claude / GPT / Gemini] → ответ
```

Что нужно: интернет, $0-20/мес.
- Claude (claude.ai) — лучший для кода
- ChatGPT (chatgpt.com) — универсальный
- Gemini (gemini.google.com) — бесплатный, 2M контекст
- DeepSeek (chat.deepseek.com) — бесплатный, неплохой

### Уровень 2: API из кода

```python
from openai import OpenAI

client = OpenAI(api_key="sk-...")
response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Напиши hello world на Rust"}]
)
print(response.choices[0].message.content)
```

Что даёт: автоматизация, интеграция в свои программы.
Нужно: API ключ, ~$0.001-0.06 за запрос.

### Уровень 3: Локальные модели (self-hosted)

```bash
# Ollama — самый простой способ
ollama run qwen2.5:1.5b    # ~1GB, бегает везде
ollama run llama3.2:3b     # ~2GB, получше
ollama run qwen2.5:7b      # ~4.5GB, надо 8GB+ RAM
```

Что даёт: приватность, бесплатно, оффлайн.
Нужно: ПК с 8GB+ RAM (или с GPU). Для этого ПК — [[LLM/Инференс и оптимизация#Домашний бенчмарк]].

### Уровень 4: RAG (добавляем свои данные)

```
Вопрос → [Search] → похожие документы из БД
                          ↓
              [LLM + документы] → ответ с цитатами
```

- [[RAG]] — полный разбор
- Инструменты: LangChain, LlamaIndex, ChromaDB, Qdrant
- Нужно: векторная БД + LLM (API или локальная)

### Уровень 5: Fine-tuning (обучаем под задачу)

Когда RAG не хватает — дообучаем модель на своих примерах.

```python
# Unsloth — самый быстрый способ
from unsloth import FastLanguageModel
model, tokenizer = FastLanguageModel.from_pretrained("qwen2.5:1.5b")
# ... loRA адаптер, train on your data
```

- [[Fine-tuning]] — полный разбор
- LoRA/QLoRA — дообучение за $5-50 вместо $100K
- Инструменты: Unsloth, Axolotl, Hugging Face TRL

## Главные отличия LLM от классического ML

| Аспект | Классика (XGBoost) | LLM |
|--------|-------------------|-----|
| **Что предсказывает** | Число / класс | Следующий токен |
| **Обучать** | Часы на CPU | Месяцы на кластере |
| **Данные** | 10K-100K строк | Триллионы токенов |
| **Дообучать** | С нуля | LoRA (1-10% весов) |
| **Prompt** | Нет | Всё |
| **Где бегает** | Любой сервер | GPU (H100+ для больших) |
| **Главный навык** | Фичи | Промпты |
