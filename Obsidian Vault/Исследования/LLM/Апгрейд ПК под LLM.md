# Апгрейд ПК под LLM

Текущая конфигурация: **i3-10105F · GTX 1050 Ti 4GB · 8GB DDR4 · SSD 187GB**

## Что тормозит Local LLM

```
Пропускная способность LLM инференса:
  VRAM  → определяет, какая модель влезает целиком
  RAM   → если модель не влезла в VRAM, нужно больше RAM
  GPU   → определяет tok/s (CUDA Cores / Tensor Cores)
  CPU   → bottleneck только если нет GPU или оффлоуд частичный
  SSD   → не bottleneck (модель грузится 1 раз)

Для этого ПК:
  ⚠️  VRAM 4GB → модели до 3B целиком, 7B частично
  ⚠️  RAM 8GB → 7B модель + Windows = своп
  ✅  GPU 768 CUDA → нормально для 3B, мало для 7B
```

## Приоритет апгрейдов

### 1️⃣ RAM: 8GB → 32GB (самый дешёвый)

**Стоимость:** ~25-35 тыс.₸ (2×16GB DDR4-3200 б/у)
**Эффект:** 7B модель перестаёт свопиться, влезает 13B в Q4 с CPU offload

```
До:   8GB   ┌──────────┬──────────────────┐    7B в Q4_K_M (4.5GB)
            │ Windows   │    7B model      │    → своп, 2-3 tok/s
            │ 2.5GB     │     4.5GB        │
            └──────────┴──────────────────┘
После: 32GB ┌──────────┬──────────────────────────────┐
            │ Windows   │  7B model  │   13B model      │   → без свопа
            │ 2.5GB     │   4.5GB    │    8.5GB         │   → 3-5 tok/s
            └──────────┴──────────────────────────────┘
```

**Вывод:** Без 32GB 7B+ модели не работают. Минимальный апгрейд.

### 2️⃣ GPU: 1050 Ti → RTX 3060 12GB / 4060 16GB

**Стоимость:** ~80-100 тыс.₸ (RTX 3060 12GB б/у), ~190-220 тыс.₸ (RTX 4060 16GB новая)

```
Модели по размеру VRAM:

▸ 4GB  (1050 Ti)    ████████████████░░░░░░░░░░  3B в Q4
▸ 8GB  (RTX 3050)   ████████████████████████░░  7B в Q4
▸ 12GB (RTX 3060)   ████████████████████████████████████████░░░  13B Q4
▸ 16GB (RTX 4060)   ██████████████████████████████████████████████████████  34B Q4
```

| GPU | VRAM | 7B Q4 | 13B Q4 | 34B Q4 | 70B Q4 | Цена б/у |
|-----|:----:|:-----:|:------:|:------:|:------:|:--------:|
| **1050 Ti** (сейчас) | 4GB | ⚠️ CPU offload | ❌ | ❌ | ❌ | — |
| **RTX 3060** | 12GB | ✅ full GPU | ✅ full GPU | ⚠️ offload | ❌ | ~90 тыс.₸ |
| **RTX 4060** | 16GB | ✅ | ✅ | ⚠️ offload | ❌ | ~200 тыс.₸ |
| **RTX 3090** | 24GB | ✅ | ✅ | ✅ Q4 | ⚠️ Q3 | ~420 тыс.₸ |
| **RTX 5070** | 12GB | ✅ (FP4) | ✅ (FP4) | ⚠️ | ❌ | ~400 тыс.₸ |

**Что даёт 3060 12GB:**
- 7B модели целиком в VRAM → **40-60 tok/s** (сейчас 6-10)
- 13B модели целиком в VRAM → **20-30 tok/s** (сейчас не работают)
- Можно запускать DeepSeek-Coder-V2 (16B), Code Llama 13B
- Требует 500W+ БП (проверь свой)

### 3️⃣ GPU апгрейд: RTX 4060 16GB

Если бюджет позволяет — идеальный вариант для LLM в этом сокете:
- 16GB VRAM → Qwen 4 Coder 32B-A3B (3B active) целиком
- 7B+13B модели с запасом
- Ada Lovelace → FP8 трансформеры, намного быстрее Pascal (1050 Ti)
- Потребление 115W vs 75W у 1050 Ti

### 4️⃣ CPU: i3-10105F → i7-10700K (опционально)

**Стоимость:** ~55-65 тыс.₸ (б/у)
**Эффект:** минимальный для LLM на GPU, важен только для CPU-only инференса

Для LLM с GPU-оффлоудом CPU мало влияет — RAM и GPU важнее.

## Сценарии после апгрейда

### Бюджетный (~35 тыс.₸) — только RAM

```
8GB → 32GB DDR4 (2×16).
GPU: оставляем 1050 Ti.
```

Что бегает:
- 7B Q4_K_M: CPU+GPU offload, **без свопа**, ~6-10 tok/s
- 3B Q4_K_M: целиком в VRAM, ~20-35 tok/s
- Qwen 4 Coder 32B-A3B: ❌ не влезет (нет)
- Лучшая модель: **Qwen 2.5 7B** / **Mistral 7B**

### Оптимальный (~130 тыс.₸) — RAM + GPU

```
8GB → 32GB DDR4 (2×16)     ~35 тыс.₸
1050 Ti → RTX 3060 12GB    ~90 тыс.₸
Проверить БП (нужен 500W+).
```

Что бегает:
- 7B Q4: целиком в VRAM → **40-60 tok/s**
- 13B Q4: целиком в VRAM → **20-30 tok/s**
- Qwen 4 Coder 32B-A3B: ⚠️ CPU offload (~10% слоёв на GPU) → ~15 tok/s
- Лучшие модели: **DeepSeek-V2-Lite 16B**, **CodeQwen 7B**, **Llama 3.3 70B** (Q3, CPU offload)

### Хардкор (~460 тыс.₸) — RAM + топ GPU

```
8GB → 64GB DDR4 (или 32GB)     ~40 тыс.₸
1050 Ti → RTX 3090 24GB (б/у)  ~420 тыс.₸
БП 750W+.
```

Что бегает:
- 34B Q4: целиком в VRAM → **25-40 tok/s**
- 70B Q3/Q4: CPU offload (24 из 80 слоёв на GPU) → **5-10 tok/s**
- Qwen 4 Coder 32B-A3B: целиком в VRAM → **50-80 tok/s**
- Llama 5 70B (Q3): ~5 tok/s
- Лучшие модели: **Qwen 4 Coder**, **Llama 5 70B**, **Mistral Small 4** (119B Q4 → CPU only, ~2 tok/s)

## Что не имеет смысла

| Апгрейд | Почему |
|---------|--------|
| **i3 → i7-10700K** | Для LLM с GPU почти нет прироста |
| **PCIe 4.0 SSD** | Модель грузится 1 раз, разницы нет |
| **1050 Ti SLI** | Не поддерживается LLM фреймворками |
| **Водянка CPU** | LLM не греют CPU |

## Проверить перед покупкой

- [ ] БП: сколько ватт? (для 3060 → 500W+, для 3090 → 750W+)
- [ ] Материнка: есть ли второй слот RAM? (для 2×16)
- [ ] Корпус: влезет ли 3060/3090?
- [ ] Монитор: 1050 Ti останется для вывода, новая GPU для Compute
