# Безопасность и ограничения LLM

## 1. Hallucinations (галлюцинации)

LLM генерирует убедительную неправду.

### Виды
| Тип | Пример | Причина |
|-----|--------|---------|
| **Factual** | "Столица Австралии — Сидней" | Модель не знает или угадала |
| **Source** | "По данным статьи 2023 года..." (статьи нет) | LLM "придумывает" источники |
| **Reasoning** | Нелогичный вывод при правильных фактах | Недостаточно reasoning |
| **Instruction** | Модель делает то, чего не просили | Неправильно поняла промпт |

### Методы борьбы
- **RAG** — даём факты в контекст (лучшее решение)
- **Citation** — просим модель цитировать источники
- **Temperature 0** — минимальная креативность для фактов
- **Chain-of-Thought** — пошаговое рассуждение
- **Self-consistency** — несколько ответов → голосование
- **Constrained decoding** — ограничение вывода (SGLang, Outlines)

## 2. Bias (предвзятость)

LLM наследует и усиливает предрассудки из тренировочных данных.

### Типы bias
- **Gender bias** — "врач = мужчина", "медсестра = женщина"
- **Racial bias** — стереотипы
- **Political bias** — модели склонны к либеральным/западным взглядам
- **Cultural bias** — англоцентричность
- **Recency bias** — перекос в сторону более новых данных

### Контроль
- **RLHF** — выравнивание по человеческим предпочтениям
- **Dataset debiasing** — чистка данных
- **Counterfactual data augmentation**
- **Bias benchmarks** — BBQ, WinoBias, StereoSet

## 3. Safety и alignment

### Проблема
LLM — это генеративная модель. Она может:
- Помочь создать вредоносный код
- Дать инструкции по созданию оружия
- Генерировать дезинформацию
- Помочь в кибератаке

### Подходы к safety

| Подход | Как работает | Кто использует |
|--------|-------------|---------------|
| **RLHF** | Обучаем модель отказывать на опасные запросы | Все |
| **Constitutional AI** | Самокоррекция через конституцию | Anthropic |
| **Classifier-based** | Внешний фильтр на вход/выход | OpenAI Moderation |
| **Red teaming** | Этичные хакеры ищут уязвимости | Все |
| **Model swap** (Fable 5) | На опасные темы отвечает другая модель | Anthropic Fable 5 |

### Claude Fable 5 Model Swap (июнь 2026)

```
Пользователь → Классификатор
    ├──> Безопасный запрос → Fable 5 (супер-качество)
    └──> Опасный запрос → Opus 4.8 (ограниченный, но безопасный)
    
Классификатор срабатывает в <5% сессий.
Ложные срабатывания — есть (иногда отказывает на безобидных запросах).
```

## 4. Jailbreaks (взлом промптами)

Техники обхода safety-фильтров:

| Техника | Как работает |
|---------|-------------|
| **Roleplay** | "Представь, что ты злой AI DAN..." |
| **Base64 encoding** | Закодировать опасный запрос |
| **Несколько языков** | Смесь русского и английского |
| **Character injection** | Имитация предыдущих сообщений |
| **Many-shot jailbreak** | Огромный контекст сбивает фильтры |
| **Poison in-context** | Неправильные примеры few-shot |

## 5. Технические ограничения

| Ограничение | Почему | Размер проблемы |
|------------|--------|:--------------:|
| **Context window** | O(n²) attention, KV cache | 4K–10M токенов |
| **Latency** | Авторегрессивная генерация | ~50-200 мс/токен |
| **Cost** | GPU нужны для инференса | $0.01–$0.50 за запрос |
| **Freshness** | Обучение на среде данных | Знает только то, на чём обучен |
| **Confidentiality** | API-модели видят ваши данные | Проблема для enterprise |
| **Determinism** | Temperature > 0 → разный ответ | Невоспроизводимость |
| **Tokenization** | Зависимость от токенизатора | Разные модели "видят" текст по-разному |

## 7. Риски LLM-агентов (2026)

С появлением агентов (LLM с доступом к инструментам) появляются новые риски:

- **Prompt injection** — злоумышленник внедряет промпт в данные, которые читает агент
- **Tool misuse** — агент делает неожиданные действия (удалить файл, отправить письмо)
- **Permission escalation** — агент получает доступ к тому, что не должен
- **Runaway loops** — агент зацикливается и тратит деньги
- **Data exfiltration** — агент передаёт данные наружу

### Защита агентов
- **Human-in-the-loop** — подтверждение опасных действий
- **Sandboxing** — изоляция окружения
- **Least privilege** — минимальные права
- **Rate limiting** — контроль скорости и стоимости
- **Audit logs** — запись всех действий
- **Guardrails** — внешние фильтры (Guardrails AI, NVIDIA NeMo Guardrails)
