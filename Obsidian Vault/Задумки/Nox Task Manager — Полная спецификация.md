# Nox Task Manager — Полная спецификация (v2.0)

> **Дата:** 15.06.2026  
> **Контекст:** Развитие [[Nox Task Manager]] из простого таск-менеджера в полноценную систему трекинга продуктивности, привычек, целей и времени.

---

## 1. ФИЛОСОФИЯ

Приложение — единый хаб для управления:
- **Задачами** (дела, проекты, подзадачи)
- **Привычками** (ежедневные/еженедельные рутины)
- **Целями** (долгосрочные KPI с декомпозицией на задачи)
- **Временем** (тайм-трекинг с помидорами / ручным стартом)
- **Энергией** (контекст: фокус-сессии, перерывы, уровень заряда)

**Ключевой принцип:** минимум трения — максимум данных. Всё должно сохраняться автоматически или в 1 клик.

## 2. ОСНОВНЫЕ МОДУЛИ

### 2.1. Dashboard / Главный экран
- **Что вижу:** сегодняшние задачи, прогресс привычек на сегодня, активная цель, активный таймер.
- **Виджеты** (настраиваемые):
  - "На сегодня" (задачи с дедлайном сегодня + просроченные)
  - "Прогресс привычек" (круг на день/неделю)
  - "Фокус-сессия" (текущий Pomodoro или Stopwatch)
  - "Краткосрочная цель" (прогрес-бар до дедлайна)
  - "Статистика за неделю" (мини-график выполненных задач)
- **Кастомизация:** Drag & drop виджетов, скрытие ненужных.

### 2.2. Задачи (Tasks)
- **CRUD:** создание, редактирование, удаление.
- **Поля задачи:**
  - Название + описание (Markdown)
  - Дата / время / повторение (ежедневно, еженедельно, monthly, custom)
  - Приоритет (P0-P4 или Low/Medium/High/Critical)
  - Статус (To Do / In Progress / Done / Canceled / Archived)
  - Категория / проект / тег (множественные)
  - Оценка времени (минуты/часы)
  - Фактическое время (из таймера)
  - Чеклист (подзадачи)
  - Связь с целью (Foreign Key → Goals)
  - Связь с привычкой (если задача — часть привычки)
- **Сортировка / фильтры:** по проекту, тегу, приоритету, статусу, дате.
- **Smart Ranking** (уже есть) — авторанжирование по urgency × importance.

### 2.3. Привычки (Habits)
- **Трекер привычек** с календарём (как GitHub contributions).
- **Типы:**
  - `boolean` (сделал / не сделал)
  - `count` (сколько раз, например "выпил 2л воды")
  - `timer` (сколько времени, например "читал 30 мин")
- **Напоминания:** в заданное время (Windows Toast Notification).
- **Streak / серия:** ведение непрерывных серий, пропуски.
- **Графики:** 7 дней, 30 дней, 90 дней — % выполнения.

### 2.4. Цели (Goals)
- **Smart Goals:**
  - Долгосрочная цель (например: "Написать курсовую")
  - Срок / дедлайн
  - Декомпозиция на задачи (связь многие-ко-многим)
  - KPI: % выполнения по подзадачам
- **Прогресс:** визуальный прогресс-бар + ETA.
- **OKR-подход:** Objective → Key Results → Tasks.

### 2.5. Тайм-трекинг (Time)
- **Режимы:**
  - Pomodoro (25/5, кастомный интервал)
  - Stopwatch (ручной старт/стоп)
  - "Я фокусируюсь" (автостарт при начале задачи)
- **Привязка к задаче:** каждый сегмент времени прикрепляется к конкретной задаче.
- **История:** лог всех сессий (когда, сколько, какая задача).
- **Графики:** распределение времени по проектам / задачам / дням.
- **Авто-пауза:** если пользователь неактивен (события ОС).

### 2.6. Напоминания / Уведомления
- **Типы:**
  - По времени (deadline, start time)
  - Интервальные (каждые N часов напоминать о привычке)
  - Умные (если задача просрочена — напомнить через час)
- **Каналы:**
  - Windows Toast (основной)
  - Звуковой сигнал (опционально)
  - Email (опционально, для важных дедлайнов)
- **Snooze:** отложить на 5/15/30 минут или на завтра.

### 2.7. Статистика и Графики
- **Общая статистика:**
  - Количество выполненных задач (день/неделя/месяц)
  - % выполнения от запланированного
  - Пиковая продуктивность (какое время дня/день недели)
- **Графики:**
  - Линейный график (завершённые задачи по дням)
  - Столбчатая диаграмма (время по проектам)
  - Круговая диаграмма (распределение типов задач)
  - Тепловая карта (календарь активности, как GitHub)
  - Burndown chart (для целей с дедлайном)
- **Pivot:** группировка по проекту, тегу, приоритету, времени.

### 2.8. Интеграции (опционально)
- **Google Drive API** — уже есть, бекап БД.
- **Google Calendar** — двухсторонняя синхронизация задач/событий.
- **Trello / Notion** — импорт задач.
- **Telegram Bot** — быстрый ввод задач с телефона.
- **GitHub / GitLab** — привязка issue к задачам.

## 3. ИНТЕРФЕЙС (UI/UX)

### 3.1. Общая концепция: Material You + Zen
- Чистый минимализм без лишних рамок и разделителей.
- Акцент на контент, не на UI-элементы.
- Тёмная тема по умолчанию (светлая опционально).
- **Боковая панель** (слева): разделы (Dashboard, Tasks, Habits, Goals, Time, Stats, Settings).
- **Хидер:** поиск (глобальный, быстрый), кнопка "Быстрая задача", уведомления, аватар.
- **Контентная область:** справа, скроллируемая.

### 3.2. Навигация
- Табы в боковой панели, с иконками и подписями.
- Collapse панели для узкого окна.
- Хоткеи (Ctrl+K → палитра команд, Ctrl+N → новая задача, Ctrl+T → таймер).

### 3.3. Окна / Модалки
- Просмотр задачи — либо боковая панель (slide-over), либо модалка.
- Редактирование — inline (кликнул на поле → редактируешь).
- Быстрая задача — модалка с 3 полями (название, приоритет, проект).
- Настройки — отдельная страница.

### 3.4. Адаптивность (?)
- Десктоп (Electron) — основной клиент.
- В перспективе — PWA для мобилок (ограниченный функционал: просмотр + быстрый ввод).

## 4. БАЗА ДАННЫХ (SQLite)

### 4.1. Сущности

```sql
-- Задачи
tasks:
  id INTEGER PRIMARY KEY AUTOINCREMENT
  title TEXT NOT NULL
  description TEXT (Markdown)
  status TEXT (todo|in_progress|done|canceled|archived)
  priority INTEGER (0-4)
  category_id INTEGER → categories
  project_id INTEGER → projects
  goal_id INTEGER → goals (NULLABLE)
  habit_id INTEGER → habits (NULLABLE)
  due_date TEXT (ISO 8601, NULLABLE)
  estimated_minutes INTEGER
  actual_minutes INTEGER
  sort_order REAL (для дроп-драг)
  created_at TEXT
  updated_at TEXT

-- Подзадачи (Checklist)
subtasks:
  id INTEGER
  task_id INTEGER → tasks
  title TEXT
  done BOOLEAN
  sort_order INTEGER

-- Проекты
projects:
  id, name, color, icon, sort_order

-- Категории / Теги
categories:
  id, name, color

-- Связь задача-тег (многие-ко-многим)
task_categories:
  task_id, category_id

-- Привычки
habits:
  id, name, type (boolean|count|timer), target_value (NULLABLE),
  unit TEXT (NULLABLE), repeat (daily|weekly|custom),
  reminder_time TEXT, color, icon, created_at

-- Лог привычек
habit_logs:
  id, habit_id, date, value (INTEGER for count, BOOLEAN for bool, INTEGER MINUTES for timer)

-- Цели
goals:
  id, title, description, deadline, target_value,
  current_value, unit, status (active|paused|completed|failed),
  created_at

-- Связь цель-задача
goal_tasks:
  goal_id, task_id

-- Тайм-трекинг сессии
time_sessions:
  id, task_id (NULLABLE), start_time, end_time, duration_minutes,
  note, date

-- Напоминания
reminders:
  id, task_id (NULLABLE), habit_id (NULLABLE), type (time|interval|smart),
  trigger_time, interval_minutes, active BOOLEAN

-- Настройки (key-value)
settings:
  key TEXT PRIMARY KEY, value TEXT
```

### 5.2. Tasks
- Table view + Kanban view (tab switcher).
- **Table:** columns = checkbox + title + priority + due date + project + timer.
- **Kanban:** 3 колонки (To Do / In Progress / Done) с drag & drop.
- Инлайн-редактирование: клик по полю → редактирование без открытия.

### 5.3. Habits
- Календарь (month view) с цветными ячейками.
- Список привычек слева, календарь справа.
- При клике на привычку — статистика (minigraph за 30 дней).

### 5.4. Goals
- Карточки целей.
- Внутри цели: прогресс-бар, список связанных задач, burndown chart.

### 5.5. Time
- Лента сессий (хронологический список).
- Pivot table / отчёт:
  - За сегодня / вчера / эту неделю / этот месяц.
  - Группировка: по задаче / проекту / категории.

### 5.6. Statistics
- Выбор периода (7/14/30/90 дней, кастомный).
- Набор графиков (переключаемых).
- Экспорт в PNG / CSV.
