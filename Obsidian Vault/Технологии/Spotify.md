# Spotify Web API

**Тип:** REST API  
**Документация:** [developer.spotify.com](https://developer.spotify.com/documentation/web-api)

## Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/search` | Поиск треков, альбомов, исполнителей |
| GET | `/playlists/{id}` | Получить плейлист |
| POST | `/playlists/{id}/tracks` | Добавить треки в плейлист |

## Авторизация

[[OAuth 2.0]] Authorization Code Flow.

- [[Playlist Adder]] — поиск и добавление треков в плейлисты
