# Proxmox VE

**Тип:** Гипервизор первого типа (Type-1 Hypervisor)  
**Сайт:** [proxmox.com](https://www.proxmox.com/)

## Возможности
- Управление ВМ (KVM) и контейнерами (LXC)
- Веб-интерфейс: `https://IP:8006`
- Bridge-сеть (`vmbr0`) для прямого доступа ВМ в LAN
- [[ZFS]] как основная ФС для пулов хранения

## Используется в проектах
- [[Home Server]] — базовый гипервизор для TrueNAS + Minecraft VM
