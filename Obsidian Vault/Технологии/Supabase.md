# Supabase

**Тип:** BaaS (Backend-as-a-Service)  
**Сайт:** [supabase.com](https://supabase.com/)

Open-source альтернатива Firebase. Предоставляет PostgreSQL, аутентификацию (GoTrue), real-time подписки, хранилище файлов.

## Возможности

- **PostgreSQL** — ACID-совместимая БД
- **Auth** — JWT-токены, OAuth, email/phone
- **Real-time** — Listen/Notify через WebSockets
- **RLS (Row-Level Security)** — защита данных на уровне строк

## Бесплатный тариф

- При простое >7 дней — проект в paused
- Восстановление — 1 клик (до 90 дней)
