# TrueNAS

**Тип:** NAS (Network Attached Storage)  
**Сайт:** [truenas.com](https://www.truenas.com/)

Операционная система для построения сетевых хранилищ. Использует [[ZFS]] для управления дисками.

## Настройка в проекте
- **Пул:** Mirror (RAID1) — 2× HDD 500 ГБ
- **Dataset:** `/mnt/ss/Data`
- **SMB Share:** `\\192.168.0.172\Data` — доступ из Windows
